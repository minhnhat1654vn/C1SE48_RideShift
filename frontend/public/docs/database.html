Điểm mạnh kiến trúc DB: schema 100% portable (prisma sqlite→postgresql chỉ đổi 1 dòng provider, 0 dòng app code); ownership rõ — FastAPI tạo/migrate schema (schema.sql, idempotent CREATE TABLE IF NOT EXISTS), Prisma chỉ là tư liệu.

2. Thông tin kết nối & vận hành

Sandbox  : postgresql://postgres@127.0.0.1:5432/rideshift   (trust auth, socket /tmp)
Docker   : postgresql://postgres:postgres@db:5432/rideshift (service `db` trong compose)
Runtime  : psycopg 3 (dict_row), connection-per-request; transactional context `db.tx()`
Lệnh Công dụng
bun run db:pg:start Khởi động PG user-space (auto-initdb db/pgdata, auto-hydrate ICU symlinks)
bun run db:pg:stop / db:pg:status Dừng / tra trạng thái
bun run db:pg:start sau reset PG data dir mất → tự initdb lại; schema+seed tự tạo lúc backend boot (db.init_db() + seed.seed())
Backend boot (tự động) main.py lifespan: schema.sql → seed (idempotent) → chạy pipeline dataset nếu dataset_trend trống

⚠️ Platform có thể inject DATABASE_URL=file:...custom.db — app/config.py tự fallback về DSN PostgreSQL ở trên khi URL không bắt đầu bằng postgres.

4. Bảng dữ liệu (11 bảng, snake_case)

4.1 Nghiệp vụ lõi

transport_mode — 7 phương tiện + tham số MCDM id PK (gasoline_motorbike, electric_motorbike, private_car, bus, bicycle, walking, taxi), name, description, icon, avg_speed_kmh, base_cost_vnd, cost_per_km_vnd, co2_per_km_g, base_accessibility, base_convenience, wait_minutes, enabled, sort_order.

lez_zone — vùng phát thải thấp id PK, name, description, coordinates TEXT (JSON [[lat,lng]…] — nguồn chuẩn, portable), active, created_at, updated_at. (Khi PostGIS bật: thêm geom geometry(Polygon,4326) + GIST — xem §5.)

policy_rule — ràng buộc LEZ theo zone × mode id PK, zone_id FK CASCADE, mode_id FK CASCADE, restriction_type (banned | conditional), condition (vd "Euro 4+"), start_time/end_time (06:00–22:00), days (Mon,Tue,…), active, created_at.

criteria_weight — trọng số TOPSIS (admin sửa được, tổng = 100) criterion UNIQUE ∈ {travelTime, cost, lezCompliance, accessibility, convenience, environment, trend}, weight (seed: 25/20/20/10/10/10/5), label.

transportation_location — marker bản đồ id PK, name, type (bus_stop | metro | brt), lat, lng, active.

4.2 Giao dịch & phiên

trip_record — mỗi lần phân tích + lựa chọn của user (nguồn liệu analytics) id PK, origin_name, dest_name, origin_district, origin_lat/lng, dest_lat/lng, distance_km, duration_min, vehicle_id (mode hiện tại của user), purpose (work|school|shopping|leisure|other), departure_hour, lez_affected, top_mode_id, top_score, avg_cost_vnd, avg_time_min, chosen_mode_id (quyết định thực tế), switched, created_at. Index: created_at, purpose.

admin_user — username UNIQUE, password_hash (sha256+salt), full_name. admin_session — token UNIQUE, user_id FK CASCADE, expires_at (8h); cookie httpOnly rs_admin_session.

4.3 Cache & dataset pipeline

air_quality_cache — cache_key UNIQUE = '{lat}:{lng}' (2 số thập phân), payload JSON (AirQualityInfo), fetched_at; TTL 30'.

dataset_trend — đầu ra pipeline pandas, feed tiêu chí trend của TOPSIS mode_id, month, share (0..1), trend_index (0..1), sample_count. Index mode_id.

dataset_run — audit log pipeline: ran_at, source_file, rows_in, rows_clean, notes.

5. PostGIS dual-mode (NFR-02)

app/db.py
├── enable_postgis_if_available()
│     CREATE EXTENSION IF NOT EXISTS postgis          ← thất bại → return False (sandbox)
│     ALTER TABLE lez_zone ADD COLUMN geom geometry(Polygon,4326)
│     CREATE INDEX lez_zone_geom_gist USING gist(geom)   ← NFR-02
│     backfill: coordinates JSON → ST_GeomFromGeoJSON
├── sync_zone_geom()  ← giữ geom đồng bộ khi admin CRUD zone
└── postgis_available() ← routers/services rẽ nhánh Shapely khi False
  • Docker/deploy: PostGIS bật → spatial query chạy trong DB (đúng chữ "PostGIS Spatial Query" của proposal §12) với GIST index.
  • Sandbox: PG user-space không kèm extension → services/geo.py dùng Shapely trong app layer; outside/partial/within cho kết quả like-for-like. Đây là rẽ nhánh tự động, không cần cấu hình tay.
